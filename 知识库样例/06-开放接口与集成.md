开放接口与集成

一、接入方式

接入方式有三种。

网页挂件是一行 script 引入，贴到网站 body 前即可，支持自定义按钮位置、主题色和欢迎语。开放接口是 REST 风格，走 HTTPS，请求和返回都是 JSON。渠道接入覆盖微信公众号、小程序、抖音企业号和邮件，公众号和小程序扫码授权，抖音需要在开放平台建应用后回填 AppID。

二、接口鉴权

每个企业一个 app_id 和 app_secret，在管理后台的开放平台里生成，secret 只显示一次。用 app_id 加 app_secret 换 access_token，有效期 7200 秒，过期重新换。请求头带 Authorization 里的 Bearer token。secret 泄露可以在后台一键重置，重置后旧 token 立即失效。

三、接口清单

换 token 用 POST 请求 v1/token。发消息用 POST 请求 v1/messages，支持文本、图片和文件。拉会话列表用 GET 请求 v1/sessions，按更新时间倒序。拉某个会话的历史消息用 GET 请求 v1/sessions 加会话 id 和 messages，支持分页。创建或更新访客信息用 POST 请求 v1/visitors，用于打通自有用户体系。只查知识库、不生成回答，用 POST 请求 v1/kb/query，返回命中的原始段落。

四、频率与限制

单企业默认每分钟 600 次，超出返回 429，响应头带重试等待时间。单次请求体上限 2MB。历史消息接口单页最多 100 条，用 cursor 翻页，不用 offset。文件消息先调上传接口拿 file_id，再发消息引用，不支持直接传二进制。

五、Webhook 回调

在后台配置回调地址，支持三类事件：消息创建、会话关闭、工单创建。回调要求 3 秒内返回 200，否则重试，间隔分别是 5 秒、30 秒、5 分钟、30 分钟，共 4 次。回调体带 signature，用 app_secret 做 HMAC-SHA256 验签。回调可能重复投递，接收方要按 event_id 做幂等。

六、单点登录

支持 SAML 2.0 和 OAuth 2.0，标准版及以上可用。开启后坐席从企业自己的门户进来，不用另建账号。支持按部门同步组织和人员，同步周期最快 10 分钟一次。

七、常见集成场景

自有 App 内嵌，用开放接口发消息，用 WebView 加载会话页，登录态通过 URL 参数透传一次性 token。订单页带上下文，创建会话时 visitor 字段带上订单号，坐席侧直接看到这单信息。知识库对外，用 v1/kb/query 只取检索结果，接进企业自己的大模型应用。
