# 服务端改造验收

> 时效说明：本记录写于 2026-11-06，当时切块 78 块、按 Markdown 标题分节。
> 2026-11-20 文档重排为中文序号分节、61 块，并新增数据层（SQLite/MySQL）、文档上传与问答记录，表中涉及块数的数字已不适用。

## 范围

RAG 客服演示原先把检索、判定、生成都放在浏览器里，Python 只做接口转发。改造后服务端承担全部业务链路，页面只负责交互与展示。

## 验证项

| 项 | 结果 |
| --- | --- |
| 服务端启动 | Python 3.13，只用标准库，无需安装依赖 |
| 知识库加载 | 8 份 Markdown，切块 78 块，服务端运行时读取 |
| 健康检查 | `/api/health` 返回文档数、块数、向量状态、对话配置状态 |
| 检索 | 「退款多久到账」Top1 命中《售后与退款政策 · 三、退款到账时间》，相似度 0.2402 |
| 意图路由 | 「你好」判为 greet，走规则回复，不进检索 |
| 无 Key 降级 | 未配 Key 时返回资料摘录，链路不中断 |
| 完整链路 | 用本地假模型验证：向量检索、查询改写、证据判定、模型生成均走服务端 |
| 向量缓存 | 落盘 `vectors.cache.json`，按文档签名与模型名失效 |
| 前端状态显示 | 运维页从 `/api/health` 读取文档数、块数与模型配置状态 |
| 控制台 | 三页均无 JS 错误 |
| 配置安全 | `config.json` 与向量缓存写入 `.gitignore`，源码无明文 Key |

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/health` | 服务状态、知识库规模、模型配置状态 |
| `GET /api/config` | 读取配置，Key 只回传是否已设置 |
| `POST /api/config` | 保存配置到本地文件 |
| `GET /api/docs` | 文档列表与切块统计 |
| `POST /api/search` | 单独检索，返回命中块与相似度 |
| `POST /api/vectors/build` | 建立向量索引 |
| `POST /api/chat` | 完整问答，返回回复、命中块与链路信息 |

## 已知限制

- 假模型只验证调用链路，未接真实模型做质量评测；评测报告中的指标来自改造前的页面链路。
- 服务端只监听 127.0.0.1，不对外暴露。
